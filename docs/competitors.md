# 法律科技平台功能與市場亮點深度分析報告

## 1\. 法律科技轉型趨勢與軟體定義

在現代企業的全球競爭版圖中，法律科技 (LegalTech) 的角色已發生本質上的蛻變——它不再僅是後勤支援的數位工具，而是驅動企業合規治理與商業敏捷性的戰略核心。隨著法律營運 (Legal Ops) 理念的普及，法律部門必須透過技術轉型，從被動的風險控管者轉型為「數據驅動的業務引擎」。

本報告將法律科技的功能架構界定為以下三個層次，作為評估平台價值的標準：

**通用功能 (Common Functions)**：消除資訊孤島、建立跨部門協作數據基礎的底層設施。

**核心功能 (Core Functions)**：針對合約生命週期或支出管理等特定專業場景，提供深度的技術賦能。

**服務亮點 (Service Highlights)**：定義用戶體驗差異、決定 ROI 轉化率與導入成功率的關鍵特性。

透過對 **Checkbox.ai, Onit, BRYTER, Juro, Anthropic Legal Plugin, Mitratech TeamConnect, LinkSquares** 等領先平台的深度掃描，我們觀察到市場正迅速向「AI 原生 (AI-Native)」的法律營運中心演進。了解這些平台的共通基礎，是法律營運專家評估其進階增值的首要步驟。

\--------------------------------------------------------------------------------

## 2\. 法律服務平台之通用功能 (Common Functions)

「通用功能」是法律部門轉型為數據驅動服務中心的骨幹。若缺乏穩健的基礎功能，法律工作將持續受困於電子郵件與試算表的「黑箱作業」中，無法實現真正的流程透明化。

根據對主流平台的觀察，四大通用功能構建了法務部門的效率基石：

**收案與分類 (Intake & Triage)**：整合 Slack, Microsoft Teams, Email 等多管道請求。如 Checkbox 透過 AI 自動捕獲並分流案件，確保法律服務能「在業務端發生的地點」即時介入。

**事項管理 (Matter Management)**：將案件進度、關聯文件與對話記錄集中於單一事實來源 (Single Source of Truth)，實現全球範圍內的協作一致性。

**自動化工作流 (Workflow Automation)**：取代繁瑣的手動審批與任務指派。透過規則引擎與 AI 的結合，確保合規流程無需人為干預即可精準執行。

**報告與分析 (Reporting & Analytics)**：藉由可視化儀表板追蹤週期時間 (Cycle Times) 與工作負載，將法律價值量化為經營指標。

**分析與影響**：法務領袖應**評估**這些功能如何從根本上改善法律部門與業務端的互動品質。透過數據的可追蹤性，我們可以**推導**出法律部門的「誠信體系」：當法律請求不再因手動作業而遺失，且處理效率具備可預測性時，法律部門便能從「流程阻礙者」轉變為真正的「商務合作夥伴」。

在掌握了共通的效率基礎後，各平台透過其「核心功能」展現出針對特定專業領域的技術天花板。

## 3\. 核心功能深度剖析 (Core Functions)

「核心功能」決定了平台解決複雜法律問題的深度。目前的市場趨勢正從「協作助理 (Co-pilot)」向「自主代辦 (Agents)」轉型，後者不僅提供建議，更強調「代為執行」。

### 合約生命週期管理 (CLM)

**Juro**：AI 原生平台的代表，其 AI 代理 (AI Agents) 協助定義模板、審閱修訂紀錄 (Redlines)，實現端到端的管理。其核心價值在於「讓 AI 直接執行合約工作 (does it for you)」，而非僅僅作為編輯工具。

**LinkSquares**：首款「全代理式 (All-Agentic)」CLM，透過 LinkAI 深度分析條款義務，並利用 Word 增益集優化修訂流程，將 AI 代理貫穿從受理到簽署的完整環節。

### 企業法律管理與支出控管 (ELM & Spend Management)

**Onit**：透過 ReviewAI 提供智慧型合約與發票掃描，其 Unity 平台將支出管理與法律事項深度綁定，提供即時的預算預警。

**Mitratech TeamConnect**：深受全球 **60% 的 Fortune 100 企業**信賴。其核心 **InvoiceIQ** 運用 AI 技術進行自動化發票審核，顯著減少細列項目 (Line-item) 的檢查時間，並透過 Spend Analytics 實現精確的成本控管。

### AI 驅動的法律生產力與助理 (AI Productivity)

**BRYTER**：利用「混合代辦 (Hybrid Agents)」結合無程式碼規則引擎，處理如理賠自動化、ISDA 審查及法院文件提取等高度結構化的法律任務。

**Anthropic Legal Plugin**：提供特定指令集以執行自動化任務：

`/review-contract`：依據組織 Playbook 進行條款審查。

`/triage-nda`：根據風險偏好快速篩選 NDA。

`/vendor-check`：自動核對供應商協議狀態。

`/brief` 與 `/respond`：產生法律簡報與自動化範本回覆。

這些核心功能是吸引不同規模企業的關鍵點，其技術深度直接決定了轉型的天花板。

## 5\. 總結與策略建議

在法律科技選型的決策矩陣中，法務領袖必須在「AI 原生」與「AI 整合」兩條路徑中做出策略抉擇。

**AI 原生與自主代理 (AI-Native & Agentic)**：以 **Juro** 與 **LinkSquares** 為代表，這類平台將 AI 視為核心動力，適合追求極速、自動化優先且合約量龐大的高成長企業。LinkSquares 的 Agentic Approach 正是通往未來「自動化法務部」的橋樑。

**AI 整合與可擴展性 (AI-Integrated & Configurable)**：以 **Mitratech TeamConnect** 與 **Onit** 為代表，適合全球佈局、強調與現有複雜架構（如財務系統、多國合規）深度融合的大型組織，提供極高的安全性與可擴展性。

**落地建議**：

**追求快速回報 (Quick Wins)**：若受困於 IT 支援不足與行政請求過多，應優先考慮 **Checkbox.ai**。其「無需 IT」的部署特性與 80% 的事項減量能力，能迅速釋放律師戰力。

**全球化支出控管**：對於管理數百家外部顧問公司的 Fortune 100 等級企業，**Mitratech** 的 60% 市場份額與專業的發票審核工具 (InvoiceIQ) 是風險最低的選擇。

**合約加速器**：若業務瓶頸在於簽署週期，**Juro** 節省 3.5 小時/每份合約的績效能為業務端帶來顯著的營收加速效果。

**最終願景**：法律科技的轉型不僅是為了提升效率，更是要徹底重塑法律部門在企業中的生態位——**從風險防範的終點，轉變為推動業務成長、加速決策鏈條的策略夥伴。**

## 6\. 律所實務管理平台（Law Firm Practice Management）

> 本節與 Legal Ops Dashboard 直接競爭。上方第 2–5 節的工具定位為「企業內部法務部門（in-house）」，本節則聚焦於**對外執業律所**的管理平台。

---

### 6.1 Clio（全球市占第一）

**定位**：中小型律所（1–50 人）的全功能雲端平台，北美市場佔有率最高，官方聲稱覆蓋超過 15 萬名律師。

| 模組 | 功能說明 |
|------|----------|
| Matter Management | 每個 Matter 集中案件、文件、任務、計費、備忘，支援 Related Matters（關聯案件，扁平關係，無父子階層） |
| 時間記錄與帳單 | 計時器隨開隨停，自動換算計費時數；支援固定費 / 時計費混合；帳單可直接 email 並線上付款（Clio Payments，整合 Stripe） |
| 客戶 Portal | 客戶透過 Clio for Clients 查閱文件、簽署合約、付款、與律師溝通，減少 email 往來 |
| 文件管理 | 整合 Google Drive、OneDrive、Dropbox；支援電子簽名（DocuSign、Adobe Sign）；有版本控制 |
| 行事曆與任務 | 與 Google Calendar / Outlook 雙向同步；**法定期間計算非原生內建**，需外掛 Court Rules 套件 |
| 信託帳戶 | 符合北美各州律師公會規範，台灣市場基本無需求 |
| 報表 | 基本的計費時數、未收款、案件數報表，客製化程度低 |

**定價**：USD 49–109 / user / month（台灣市場偏高）

**弱點**：
- 審級聯動邏輯缺失（Related Matters 為手動關聯，無父子階層、無結案聯動提示）
- 法定期間計算依賴第三方套件，非在地化
- 介面英文為主，無繁中支援
- 信託帳戶功能對台灣律所無用，但計費在 plan 內

---

### 6.2 MyCase

**定位**：美國中型律所，強調**一體化**（案件管理 + 帳單 + 客戶溝通整合在同一平台）。

| 功能 | 說明 |
|------|------|
| 案件管理 | 支援文件、任務、日曆、備忘集中管理 |
| 客戶 Portal | 類似 Clio，可線上付款、電子簽名 |
| 行銷 CRM（MyCase Grow） | 提供潛在客戶追蹤（Lead Tracking）、線上預約諮詢，整合至案件建立流程 |
| 帳單 | 支援 ACH 直扣、信用卡；有律師費用融資選項 |

**定價**：USD 49–89 / user / month

**弱點**：功能廣度不如 Clio，報表較弱，無律師績效 KPI 儀表板。

---

### 6.3 LEAP

**定位**：雲端原生律所管理平台，澳洲起家，強勢市場為澳洲、英國、美國、加拿大。

| 功能 | 說明 |
|------|------|
| 文件自動化 | 與 Microsoft Word 深度整合，依案件資料自動填入模板，是 LEAP 最大差異化點 |
| 法定費用計算 | 內建各司法管轄區法定費用表（澳洲、英國），**本地化深度是亞洲市場最弱的地方** |
| Matter Management | 功能完整，支援案件時間軸 |
| 信託帳戶 | 澳洲/英國合規，台灣無對應需求 |

**定價**：依地區方案，約 AUD 99–199 / user / month

**弱點**：亞洲市場無本地化版本，文件模板以英語普通法體系為基礎，對台灣民法體系幾乎無法直接使用。

---

### 6.4 Smokeball

**定位**：小型律所（1–10 人），以**自動計時**（Auto-Time Capture）聞名，所有在案件相關文件上的操作都自動記錄工時。

| 功能 | 說明 |
|------|------|
| 自動工時捕捉 | 偵測律師在 Word、Outlook 等工具上的作業時間，自動記錄至對應案件 |
| 文件管理 | 內建 Word 整合，豐富的法律文件模板庫（以英語普通法為主） |
| 效率報表 | 提供律師生產力報告（文件數、工時、案件數） |

**弱點**：規模擴充性差，超過 20 人規模開始出現瓶頸；無亞洲本地化。

---

### 6.5 Filevine

**定位**：以**人身傷害 / 訴訟型律所**為主要客群，強調案件進度追蹤與文件管理，近年快速整合 AI 功能。

| 功能 | 說明 |
|------|------|
| 案件流程追蹤 | 高度可設定的案件階段（Pipeline），支援拖曳式狀態管理 |
| AI 文件摘要 | 自動摘要醫療記錄、合約，提取關鍵資料點 |
| 任務自動化 | 觸發式任務（案件進入某階段自動建立任務清單） |
| 報表 | 比 Clio 更強的 KPI 報表，支援律師生產力與案件週期分析 |

**定價**：USD 39–79 / user / month + 設定費

**弱點**：介面複雜，上手曲線陡；以美國訴訟型態設計，不適合台灣民刑事業務結構。

### 6.6 市場空白：台灣與亞洲本地化律所管理工具

目前主要律所實務管理平台（Clio、MyCase、LEAP、Smokeball、Filevine）**均以英語普通法（Common Law）司法管轄區設計**，對台灣的需求：

| 需求 | 現有平台狀況 |
|------|-------------|
| 繁中介面 | 均無 |
| 台灣民法 / 刑事訴訟審級邏輯 | 均無（需自行設定或放棄） |
| 法定期間自動計算（台灣民訴法） | 均無 |
| 台灣電子發票 / 統一編號帳單格式 | 均無 |
| 新台幣計費 / 台灣信託帳戶規範 | 均無 |

**策略結語**：Legal Ops Dashboard 進入的是一個在台灣**幾乎無直接競品**的細分市場。競爭對手主要來自律所沿用的 Excel / Google Sheets 自建系統，而非上述國際平台。差異化重點應持續深化：**台灣審級邏輯（父子案件聯動）、法定期間在地化警示、繁中操作體驗**。
